# TTML TRANSLATER

> Windows 平台 TTML 小工具 => [ranhengzhang/c-ttml-trans-tool](https://github.com/ranhengzhang/c-ttml-trans-tool)

## 使用方式

前往 [Issue](../../issues) 页面，选择想要转换的文件格式对应的 Issue 模板，粘贴想要转换的 TTML 文件链接。提交后机器人将在处理完成后附上下载页面链接以及文件内容。

## 已支持文件格式

- `*.lrc` (Lyric)
- `*.spl` (Salt Player Lyrics)
- `*.lys` (Lyricify Syllable)
- `*.ass` (Advanced SubStation Alpha)
